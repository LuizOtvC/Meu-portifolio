Casa Fácil

O casa fácil é um projeto que visa ajudar as pessoas em moradias a encontrarem profissionais da área que eles precisam em forma de freelance, e assim, ajudar os moradores a resolver os seus problemas, e aos proffisionais, para encontrar service de forma mais facil, o sistema conta com um sistema de match making, pra ajudar na hora de decidir se o proffisional é qualificado para o serviço ou não

Tecnologias utilizadas

  • Java
  • Spring boot
  • MySql
  • JPA
  • JavaScript
  • CSS
  • BootStrap
